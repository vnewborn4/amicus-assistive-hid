# Amicus Assistive HID Bridge (RP2350 / Raspberry Pi Pico 2)

Open-source assistive USB HID accessibility controller firmware for the RP2350 (Raspberry Pi Pico 2) featuring:
- Hardware negative-veto (`<10ms` emergency physical override / cancel switch)
- Deterministic assistive cursor stabilization and switch-access input mapping
- **Strictly Assistive-Only:** Zero synthetic tremor or human-mimicry features.
